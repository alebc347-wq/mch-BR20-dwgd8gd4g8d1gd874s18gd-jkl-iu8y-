1. THE CAUSE OF THE ISSUE
-------------------------------------------------------------------
Due to a path extraction bug (FileNotFoundError) in our auto-updater 
script during deployment, the synchronization loop failed to properly 
determine the active standby states. Consequently, two mirror servers 
connected to Discord Gateway simultaneously. 

When a management command (.dm all) was issued to notify our guild owners, 
both instances processed the message loop concurrently, leading to 
accidental duplicate direct messages.

-------------------------------------------------------------------
2. CODE IMPLEMENTATION OF THE FIX (ACTIVE-PASSIVE FILTER)
-------------------------------------------------------------------
We have completely rewritten our system's gateway handler and cluster 
coordination. We implemented a strict active-passive coordination mechanism 
using a designated Discord channel.

A snippet of the fix deployed in our `main.py` and `cogs/discord_control.py` 
is detailed below.

[A] main.py (Global active check filter to silence passive nodes):
```python
        # Register active-passive command filters (Only respond if active)
        @self.check
        async def globally_check_active(ctx):
            return getattr(ctx.bot, "is_active_node", True)

        @self.tree.interaction_check
        async def globally_check_interaction(interaction: discord.Interaction):
            return getattr(interaction.client, "is_active_node", True)

    async def on_tree_error(self, interaction: discord.Interaction, error: discord.app_commands.AppCommandError):
        # Silence all errors on passive node
        if not getattr(self, "is_active_node", True):
            return
        ...

    async def on_command_error(self, ctx: commands.Context, error: commands.CommandError):
        # Silence all command error events on passive standby node
        if not getattr(self, "is_active_node", True) or isinstance(error, commands.CheckFailure):
            return
        ...
```

[B] cogs/discord_control.py (Heartbeat loop and automatic failover switch):
```python
            # Automatic failover logic
            # Determine active nodes within 35 seconds of heartbeat
            active_nodes = [
                sid for sid, ltime in data["heartbeats"].items()
                if now_time - ltime < 35
            ]

            locked_server = data.get("locked", "")
            current_active = data.get("active", "")

            if locked_server:
                data["active"] = locked_server
            else:
                if not current_active or current_active not in active_nodes:
                    if active_nodes:
                        active_nodes.sort()
                        data["active"] = active_nodes[0]
                    else:
                        data["active"] = ""

            # Assign local execution state
            final_active = data.get("active")
            if final_active == self.server_id:
                self.bot.is_active_node = True # Deployed online
            else:
                self.bot.is_active_node = False # Silenced to standby
```
